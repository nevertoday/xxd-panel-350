# XXD Panel 350｜霓虹精灵

上半保留原照，下半删掉杂物，只把主体和紧挨它的一小片环境画成一张安静、浅淡、用细墨线认真勾出的写实线稿；主体却变成一只软胖的发光精灵：保留外形，身体是一圈套一圈的彩虹光晕，脸上只有两颗小圆眼和一道短横线嘴，身边再飘着、蹲着几只小精灵，被一道彩色光弧或烟带连起来；右下角一行铅笔小字题目。

## 适用场景与解决的问题

适合一个平常角落里有一个清楚主体的照片：沙发上的猫、窗台的盆栽、门廊的狗、桌上的茶壶、墙边的自行车、厨房的锅、老电视、红门。也适合构图差、背景乱、主体小的照片——下半会删掉杂物，把环境退成浅淡线稿，只让主体和几只小精灵发光，把它救成一个“平常角落突然被一群看不见的小家伙占领了”的画面。照片本身是街道、走廊或室内全景时，只取最有代表性的一个单体或片段。

关键是细而准、按照片结构和透视认真勾出的浅淡线稿，与没有线、全靠柔和光晕成形的软胖精灵叠在一起：主体保留外形，身体一圈套一圈从最鲜明的照片色向外过渡成粉、橙、黄、绿、蓝的彩虹光晕，脸上只有两颗小圆眼和一道短横线嘴；几只小精灵从物件后面探头、蹲在边上或拖着一缕彩色的烟，由一道光弧连起来；右下角一行像画边题目的手写细铅笔小字。避免完整场景复刻、背景填满、光滑的商业卡通、精灵画成有线描的普通卡通角色、整张画都变成彩色、主体认不出、线稿潦草、光晕糊成脏色和精灵多到挤满画面。

## 使用窍门

- **先给一张清楚的照片：** 先选一张主体、动作和关系都容易辨认的图，再决定输出方式与比例。
- **一句话串起参数：** 直接说“上下对照 / 左右对照 / 纯设计 + 16:9 / 3:4 / 手机壁纸”，也可以补充电脑、平板或电子手表尺寸。
- **把必须保留的内容说清楚：** 指定人物、物件、动作、关系和文字；避免同时规定过多布局细节，让风格有空间完成设计。
- **文字有三种选择：** 让模型按图片智能生成、用 `--text exact --copy` 锁定逐字文案，或用 `--text none` 完全不要文字。
- **说明现实区与设计区：** 上下或左右对照时，注明哪一侧保留照片、哪一侧负责设计转译；纯设计和壁纸则说明整张画布都要重新设计。
- **先单张试，再批量做：** 先用一张图确认模式、比例、文字和语言，再把同一套参数用于目录批处理；每轮只改一个变量，结果更容易比较。

## 开始使用

从 GitHub 安装：

```bash
npx skills add https://github.com/nevertoday/xxd-panel-350 --skill xxd-panel-350
```

安装后重新启动 Agent 会话，然后调用 `$xxd-panel-350`。也可以按需追加 `--global --agent codex --yes` 做用户级安装。

常用调用示例：

```text
/xxd-panel-350 photo.jpg --mode top-bottom --size 3:4 --text prompt --locale zh-CN
/xxd-panel-350 photo.jpg --mode left-right --size 16:9 --text prompt --locale en-US
/xxd-panel-350 photo.jpg --mode design-only --size 9:16 --text none --prefs off
/xxd-panel-350 ./photos --mode design-only --size auto,3:4 --text prompt --locale ja-JP
```

完整运行契约见 [SKILL.md](SKILL.md)；运行适配器见 [英文](references/xxd-panel-350-prompt.en.md) 与 [中文](references/xxd-panel-350-prompt.zh-CN.md)。

## 快速判断：Panel 350 适合你吗？

既要保留源图身份，也要重新构图；既要材质特征，也要主动留白。可选准确文字、智能文案或无文字；支持单图、递归目录批量以及下方四种交付模式。

## 四种输出模式

- `top-bottom`：整张画布只有上下两个全宽区域，现实照片在上、设计在下，严格各占 50%。
- `left-right`：整张画布只有左右两个全高区域，现实照片在左、设计在右，严格各占 50%，不会旋转成上下结构。
- `design-only`：整张画布只呈现 Panel 350 的设计转译，照片只作为不可见参考。
- `wallpaper-pack`：按手机、iPad、桌面和手表分别生成完整设计壁纸，可选 `linked` 连贯套装或 `independent` 四张独立。

支持多选模式与比例（`1:1`、`3:4`、`4:3`、`4:5`、`5:4`、`2:3`、`3:2`、`9:16`、`16:9`、`21:9`、`5:7`、`7:5` 或准确像素），以及模型生成文字、准确文字和无文字。传入目录会递归扫描图片，每张源图独立处理，共用一次交付设置；最终 PNG 平铺放入一个新任务目录。
